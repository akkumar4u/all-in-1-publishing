# Install "All in 1 Publishing" (one time, about 3 minutes)

After this you never install or update anything by hand — new versions arrive by themselves.

1. **Get the shared folder on your computer.**
   - Google Drive: install *Drive for desktop*, open the shared folder **All-in-1-Publishing**, right-click → *Offline access → Available offline*.
   - Dropbox: install the Dropbox app, open the folder, right-click → *Make available offline*.
   Do not move or rename the folder afterwards, and do not edit anything inside it.
2. Open Chrome → `chrome://extensions` → turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the synced folder (the one that contains `manifest.json`).
4. Pin the extension (puzzle icon → pin). Click its icon to open the side panel.

## Updates
- A new version is picked up within about 5–10 minutes of the owner publishing it.
- If the side panel is closed and nothing is running, the extension reloads itself.
- If the panel is open you see a green bar: **A new version is ready → Update now**. Click it when you are between tasks (it clears what is typed in the panel).
- Chrome may show "Disable developer mode extensions" when it starts. Choose *Cancel* / close the message — do not disable it.

## If something looks wrong
- Make sure the folder says "available offline" / "mirrored" (not "online only").
- `chrome://extensions` → find the extension → **Reload** (the circular arrow).
- Still stuck: send the owner the version shown at the bottom of the side panel and a screenshot.
